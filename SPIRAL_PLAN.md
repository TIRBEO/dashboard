# Tirbeo Rebuild — Spiral Plan

## Spiral 1 — Foundation
- Clean monorepo structure
- Core Prisma schema (User, Session, Profile, Role, Permission)
- Auth system (JWT + Argon2 + DB sessions)
- Design system packages
- API foundation
- Account app (login/register)

## Spiral 2 — User Platform
- User dashboard
- Profile management
- Sessions & devices
- Security center (2FA, passkeys)
- Notifications
- User preferences

## Spiral 3 — Administration
- Admin layout + navigation
- User directory (CRUD, search, filter)
- Role management (RBAC)
- Permission engine (ABAC)
- Audit system
- Admin dashboard with real data

## Spiral 4 — Extensions
- Application registry
- Feature flags
- Reports & analytics
- Data export
- Settings center

## Spiral 5 — Support & Content
- Support tickets
- Knowledge base
- Blog system (CMS)
- Live page editing
- Media library

## Spiral 6 — Infrastructure
- System health monitoring
- Load balancing prep
- Observability
- Disaster recovery
- Performance optimization

## Spiral 7 — Future Products
- Additional Tirbeo applications
- Multi-product identity reuse
